28th CoRe Seminar

Date and time:  2022.07.25 Mon. 15:00-17:00
Venue:  Online
Speaker:  KAWAHARA, Jun (Kyoto U., Group B01)
Title:  Reconfillion: a combinatorial reconfiguration solver
Summary: 
In this talk, we introduce a Python library for solving combinatorial reconfiguration problems, which is under development in our project. The library is based on graphillion, a subgraph enumeration library. It can solve combinatorial reconfiguration problems for families of sets that can be represented by graphillion. We also introduce the algorithm used in the library.
